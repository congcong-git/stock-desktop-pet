# 股票观察器桌面宠物 PRD

**文档版本：** V2.1
**产品类型：** Windows 桌面股票观察工具（桌面宠物形态）
**文档状态：** 需求已确认（2026-09-05）；V2.0 已交付，V2.1（素材库管理）开发中
**基于版本：** V1.0 股票观察器桌面小组件

---

## 1. 产品概述

### 1.1 背景

V1.0 以"常驻桌面的大面板"形态展示股票行情，窗口占用面积大、视觉形态偏工具化。V2.0 将产品形态改造为**桌面宠物**：

- 主窗口缩小为宠物大小的透明角色，常驻桌面；
- 以"电影牛"形象作为宠物本体；
- 所有业务功能通过**右键弹出菜单**进入互动；
- 行情盈亏实时驱动宠物表情与状态反馈。

### 1.2 产品定位

在保留 V1.0 全部股票观察能力的基础上，用桌面宠物提供更轻量、有陪伴感的股票盯盘体验。

> "桌面上一只电影牛替我看盘：涨了它开心，跌了它沮丧，右键一按，所有功能都在。"

### 1.3 核心价值（相对 V1.0）

1. 极小占屏：透明宠物窗口，不遮挡工作区；
2. 视觉友好：情感化角色替代生硬的数字面板；
3. 零打扰：功能全部收进右键菜单，需要时才展开；
4. 能力不缩水：行情、自选、持仓、盈亏、快照等 V1.0 能力完整保留。

# 4. 详细需求

## 4.1 宠物窗口形态

| 项 | 规格 |
|---|---|
| 窗口尺寸 | 约 240×300（依据素材实际比例微调），**不可缩放** |
| 窗口样式 | `transparent: true`、`frame: false`、`resizable: false` |
| 置顶 | `alwaysOnTop: true` |
| 任务栏 | `skipTaskbar: true` |
| 背景 | 窗口透明，仅渲染宠物本体像素 |
| 启动位置 | 默认屏幕右下角附近（`workArea` 计算），不覆盖任务栏 |
| 拖动 | 按住角色区域左键拖动窗口（`-webkit-app-region: drag` 方案） |
| 穿透 | **不做**整窗鼠标穿透（角色可交互，拖动/右键均需接收鼠标事件） |

## 4.2 宠物本体素材（已定稿）

1. 形象：用户从 3 版候选选定 **① 金黄毛绒 3D 牛**（金黄蓬松毛、奶白口鼻、灰蓝弯角、3D 电影渲染质感），用于生成表情素材；
2. 背景：AI 生成图带纯白背景，经 `scripts/make-pet-assets.ps1`（连通域 flood-fill + 邻接过渡渐变）去除为透明 PNG；
3. 输出：`src/assets/pet/{idle,happy,sad}.png`（1024×1024），由构建脚本复制至 `dist/assets/pet/` 随包分发；
4. 画风约束：素材整体保留 3D 电影质感，与透明窗口合成时使用柔和投影/阴影避免漂浮感。

## 4.3 表情与行情联动（已定稿：多表情图切换）

| 行情状态 | 宠物状态 | 素材 | 触发条件 |
|---|---|---|---|
| 盈利 | happy（开心） | `happy.png` | 当日总盈亏 > 0 |
| 亏损 | sad（沮丧） | `sad.png` | 当日总盈亏 < 0 |
| 持平 / 未开盘 / 无持仓 | idle（待机） | `idle.png` | 其余情况 |
| 网络异常 | idle | 沿用上一状态素材 | 沿用 V1.0 失败不更新规则 |

- 用户选择**多张表情图切换**方案：同一造型分别生成开心 / 沮丧 / 中性三张图；
- 表情随 `market:refresh` 结果（`profitStatus`）切换，与行情刷新节奏一致；
- 切换时以 mood 为 key 重建 `<img>`，配合淡入动画（`moodIn`）；
- 图片加载失败时自动回退到内置 SVG 占位牛，不显示破图；
- 角色随心情播放容器动画：待机浮动、开心弹跳、沮丧低落。

## 4.4 底部状态胶囊（显示内容可配置）★新增

角色下方的状态胶囊（可点击刷新）默认显示当日盈亏，现扩展为**可在右键菜单中切换的多模式显示**：

| # | 显示模式 | 示例 | 说明 |
|---|---|---|---|
| 1 | 今日盈亏（金额） | `今日 亏损 -123.45` | 默认，保持 V2.0 现有行为 |
| 2 | 盈亏金额 + 当日涨跌幅 | `今日 亏损 -123.45（-1.23%）` | 金额与百分比同屏 |
| 3 | 当日涨跌幅（百分比） | `今日 亏损 -1.23%` | 仅百分比 |
| 4 | 持仓总市值 / 总成本 | `市值 ¥25,430 / 成本 ¥26,100` | 金额缩写显示 |
| 5 | 持仓数 · 自选数 | `持仓 2 · 自选 5` | 数量统计 |
| 6 | 持仓涨跌轮播 | `茅台 +0.35%` → `平安 -1.02%` | 逐只轮播，无持仓时提示 |
| 7 | 盯盘股行情 | `贵州茅台 ¥1,720.00 +0.35%` | 从自选/持仓中选一只固定盯盘 |
| 8 | 自定义文字 | 用户自定 | 输入一段固定文字替换全部行情信息 |

约束：
- 入口放于右键菜单「底部显示内容」子菜单，当前模式带勾选标记，点击即切换；
- 选择状态持久化（重启后保持上次选择）；
- 「持仓涨跌轮播」与「盯盘股行情」在非交易时段沿用最近行情照常展示；
- 自定义文字支持任意中英文短句，超宽省略显示，悬停可见全文；
- 胶囊左侧**状态点**（`.chip-dot`）遵循 BR009–BR011 的涨跌配色：**涨红 / 跌绿 / 持平灰**，色值与面板 `.rise` / `.fall` 一致。其取值**独立于宠物心情**（不随「预览形象」变化）：模式 6 / 7 跟随当前轮播或盯盘的那只股，其余模式跟随整体盈亏状态。

## 4.5 宠物外观（情绪素材替换）★重做

桌宠形象**按情绪分别替换**，三种盈亏状态各自独立绑定一张图片、一个动图或一段视频；不再使用"皮肤文件夹"整体导入。

### 4.5.1 概念

- 三种情绪独立设置素材，互不影响：
  - **待机（持平 idle）** / **开心（盈利 happy）** / **沮丧（亏损 sad）**；
- 每种情绪未替换时使用内置默认形象（占位角色），更换后立即生效、重启保持；
- 素材是"引用绑定"，同一个文件可同时被多个情绪使用。

### 4.5.2 素材类型

| 类型 | 支持格式 | 说明 |
|---|---|---|
| 静态图 | `png` / `jpg/jpeg` | 单帧形象 |
| 动图 | `png`(APNG) / `webp`(动画) / `gif` | 放入即循环播放 |
| 视频 | `webm` / `mp4` / `mov` / `m4v` | 自动循环静音播放 |

- 视频通过 `<video>` 元素播放，推荐使用带 **Alpha 透明通道的 webm**（如 AI 生成的透明背景动画）；普通 mp4 无透明通道时会以不透明底色矩形显示在桌面上；
- 图片/动图/视频可在三种情绪间任意混合使用；
- 全部素材在 `216×240px` 显示区内等比缩放居中，不裁切、带投影。

### 4.5.3 交互

**入口**：右键 →「宠物外观」子菜单：

```text
宠物外观
 ────────────────
 打开素材库管理…               → 打开素材库可视化面板（推荐入口，见 4.5.5）
 ────────────────
 待机显示：默认形象             （只读，显示当前绑定素材名）
 开心显示：happy_dance.mp4      （只读）
 沮丧显示：默认形象             （只读）
 ────────────────
 更换待机（持平）显示…          → 弹系统文件选择框（快速方式，保留）
 更换开心（盈利）显示…          → 弹系统文件选择框（快速方式，保留）
 更换沮丧（亏损）显示…          → 弹系统文件选择框（快速方式，保留）
 ────────────────
 恢复默认显示                   → 待机/开心/沮丧/全部恢复
 打开素材目录                   → 资源管理器直达用户素材目录
```

- **更换某情绪显示…**：弹出系统文件选择框（图片与视频过滤）→ 选取文件即复制到素材目录并绑定到该情绪，**当前桌宠立即以该素材显示**（自动静音循环）；
- 文件选择框可取消；取消不改动现有绑定；
- 「恢复默认显示」：可单情绪恢复或全部恢复；
- 素材统一存于 `userData/mood-media/`（同名自动追加 "(2)" 序号，不覆盖旧文件）；「打开素材目录」方便手工清理，被删除的素材对应绑定自动回退默认，不影响运行。

### 4.5.4 显示与回退规则

- 心情动画（浮动/弹跳）作用于整体舞台，不改变素材本身；
- 某情绪绑定的素材**加载失败/文件缺失** → 自动回退该情绪的内置默认形象 → 仍失败再显示矢量占位角色，桌宠不会消失；
- 素材即时生效，无需重启与重新构建。

### 4.5.5 素材库管理面板 ★V2.1 新增

在保留右键快速更换（4.5.3）的前提下，新增独立**素材库小窗**，把素材从"弹框选文件"升级为"可视化管理"。

**窗口规格**

| 项 | 规格 |
|---|---|
| 入口 | 宠物右键 →「宠物外观 → 打开素材库管理…」（子菜单首项，固定展示） |
| 形态 | 约 980×720 深色小窗，可拉伸（最小 760×560），**单实例**（重复打开时聚焦已有窗口） |
| 关闭 | 关闭不影响宠物驻留；宠物正处于"试穿"时自动结束试穿，恢复原绑定显示 |

**界面分区**

1. 情绪槽位区：待机 / 开心 / 沮丧三张卡片，展示各自当前绑定素材的缩略图与文件名；点「移除」恢复该情绪默认形象；
2. 素材库网格：展示全部已导入素材（图片缩略 / 视频悬停或选中即循环播放）；卡片显示类型标签与已绑定情绪角标；素材目录被外部增删时自动收敛；
3. 底部操作条：选中素材后提供绑定、试穿、重命名、删除操作；未选中时给出引导文案。

**功能项**

| 功能 | 规则 |
|---|---|
| 批量导入 | 「导入素材…」一次多选；格式与体积校验同 4.5.2，被拒文件计数提示；同名自动追加序号；导入成功由主进程广播刷新素材库与宠物目录索引 |
| 绑定 / 解除 | 选中素材一键设为待机/开心/沮丧；同一素材可同时绑定多个情绪；「移除」与「删除」自动解除对应绑定 |
| 试穿（预览） | **不写入绑定**，仅把素材临时覆盖到宠物播放以对比效果；点「停止试穿」、换绑或关闭素材库即恢复原状；试穿素材被删除/重命名时自动跟随（停止 / 更新地址） |
| 重命名 | 修改文件名；**扩展名类型不可改变**（图片↔图片、视频↔视频），防止绑定素材类型错乱；重名/占用时明确提示 |
| 删除 | 二次确认（4 秒内再次点击生效）后删除文件；绑定该素材的情绪自动恢复默认、试穿自动停止；被系统占用的文件删除失败给出提示 |

**数据与同步（重要）**

- 绑定关系唯一数据源为主进程 `Data/mood-bindings.json`（V2.1 新增文件）；宠物启动时以主进程绑定为准，并把老版本本地缓存自动上传迁移；
- 宠物、素材库、右键菜单三方经主进程**广播实时一致**，消除多窗口各存一份导致的绑定漂移；
- 素材文件仍存 `userData/mood-media/`；素材库打开期间手工增删文件后点「刷新」同步。

**回退安全**：绑定素材缺失 / 加载失败时，该情绪自动回退默认形象（同 4.5.4），桌宠不会消失。

## 4.5.6 素材去背景（AI 抠图）★V2.2 新增

在素材库面板中对**静态图**做本地抠图，生成透明 PNG 素材，保存时可直接绑定到情绪槽位。

**适用素材**

| 素材类型 | 是否支持 | 说明 |
|---|---|---|
| 静态图（png / jpg / jpeg / webp） | 支持 | 单帧图片 |
| 动图（gif / apng / 动图 webp） | 不支持 | 需逐帧处理，本期不做 |
| 视频（webm / mp4 / mov / m4v） | 不支持 | 同上 |

不支持的素材「去背景」按钮禁用，鼠标悬停提示原因。

**处理流程**

1. 选中素材 → 点「去背景」→ 弹出面板，左「原图」/ 右「去背景后」（棋盘格表示透明区域）；
2. 面板打开即自动执行：加载模型（加载中）→ 推理生成掩膜（识别中）→ 就绪；
3. 就绪后可拖动滑杆微调，**只重做合成、不重复推理**：

| 参数 | 范围 / 默认 | 规则 |
|---|---|---|
| 阈值 | 0.05 – 0.95 / 0.50 | 调小：抠得更干净，边缘细节可能被误删；调大：保留更多边缘 |
| 边缘羽化 | 0 – 6 px / 1 px | 柔化边缘锯齿；数值过大产生半透明毛边 |

4. 保存方式：

| 按钮 | 规则 |
|---|---|
| 设为待机 / 设为开心 / 设为沮丧 | 保存并绑定到该情绪；原素材已绑定该情绪时自动接管 |
| 仅保存不绑定 | 只写入素材库，不改变现有绑定 |
| 取消 / 关闭 | 放弃结果，不落盘 |

**存储与命名**：结果写入 `userData/mood-media/<原文件名>-nobg.png`，同名自动追加序号；保存成功后素材库列表与宠物目录索引同步刷新，生成结果可像普通素材一样绑定 / 试穿 / 重命名 / 删除。

**技术方案（要点）**

- 模型 u2netp（ONNX），运行时 onnxruntime-web 1.15，以 vendor 资源随仓库分发（`build/vendor/ort` → `dist/ort`），不依赖 npm 安装；
- 打包后 `asar` 内的 wasm 与模型无法被渲染层 `fetch`，首次使用时由主进程复制到 `userData/assets/`，并按 `RUNTIME_ASSETS_TAG` 做版本化增量更新；
- 推理前统一缩放到模型输入尺寸，再按原图尺寸合成输出；
- 全部在本机完成，**不上传图片、不依赖网络**。

**异常与边界**

- 模型 / 运行时缺失或推理失败时给出提示，不影响素材库其它功能；
- 原图永不修改，失败可直接重试；
- 复杂背景、半透明主体或主体与背景颜色接近时需人工调参，不做自动兜底。

## 4.6 右键菜单

在宠物区域 `contextmenu` 弹出**原生 Electron 菜单**：


## 4.7 管理面板窗口

| 项 | 规格 |
|---|---|
| 触发 | 右键菜单「自选/持仓管理」「搜索添加股票」「今日快照」等 |

| 数据共享 | 面板与宠物共用同一 `userData/Data` 本地文件与主进程行情逻辑 |

## 4.8 行情与本地数据

全部沿用 V1.0 主进程能力（本 PRD 不重复描述）：
- 每 10 秒刷新实时行情；
- 11:30 / 15:00 快照保存与守护补拍；
- 非交易时间从最近快照恢复展示；
- 自选/持仓/股票名缓存/交易配置的本地存储与损坏自愈。

## 4.9 系统托盘 ★V2.2 新增

宠物窗口 `skipTaskbar`（不占任务栏），管理面板最小化后任务栏入口不易定位，因此提供**常驻托盘**作为统一的找回通道。

| 项 | 规格 |
|---|---|
| 图标 | 应用图标（32px，`electron/tray-icon.png`），随应用启动创建，**不随窗口最小化消失** |
| 左键单击 / 双击 | 唤回管理面板：已存在则先 `restore()` 再 `show()` + `focus()`；不存在则新建 |
| 右键 | 弹出托盘菜单：打开管理面板 / 打开宠物素材库 / 桌宠回到屏幕右下角 / 打开数据目录 / 退出 |
| 桌宠复位 | 按主屏 `workArea` 把宠物放回右下角，应对宠物被拖出屏幕或位置异常 |
| 退出 | `app.quit()`，宠物与所有窗口一并关闭 |
| 关联项 | 设置 `app.setAppUserModelId`（与 `build.appId` 一致），修复 Windows 任务栏按钮分组异常 |

**约束**

- 托盘只作为「找回入口」，不改变窗口原有的最小化 / 关闭语义；
- 仅关闭宠物窗口或托盘菜单「退出」才结束进程（沿用 3.1「退出」规则）；
- 托盘图标缺失时不阻断启动（降级为无托盘，其余功能不受影响）。

# 5. 技术方案

## 5.1 进程与窗口结构

| 窗口 | 加载页面 | 说明 |
|---|---|---|
| petWindow（主） | `pet.html` → `pet.js` | 透明置顶小窗，宠物渲染 |
| panelWindow（按需） | `index.html` → `renderer.js` | V1.0 管理面板，单实例 |
| mediaWindow（按需） | `media.html` → `media.js` | 宠物素材库小窗（V2.1），单实例 |

- 主进程窗口管理：`createPetWindow()`（常驻）、`openPanelWindow(section)`、`createMediaWindow()`（素材库，单实例）；
- petWindow 常驻，panelWindow / mediaWindow 仅菜单触发时打开、可同时存在；
- `window-all-closed` 逻辑调整为**所有窗口关闭即退出**不变；面板关闭不退出，由菜单"退出"统一收口。

## 5.2 构建（esbuild 多入口）

`scripts/build-renderer.js` 采用多入口打包：

- `src/renderer.jsx` → `dist/renderer.js`（管理面板，沿用现有 UI）；
- `src/pet.jsx` → `dist/pet.js`（宠物渲染）；
- `src/media.jsx` → `dist/media.js`（宠物素材库，V2.1 新增）；
- 对应 HTML 显式复制到 `dist/`，CSS 由 esbuild 按入口同名输出（`renderer.css` / `pet.css` / `media.css`）。

## 5.3 右键菜单

- preload 新增 `openPetMenu(payload)`；主进程 `ipcMain.on("pet:menu")` 用 `Menu.buildFromTemplate` 构建并 `popup`；
- 菜单动态注入最新盈亏概要文本；
- 「宠物外观」子菜单首项为「打开素材库管理…」；右键快速「更换××显示…」导入成功后广播素材目录变化。

### 5.3.1 素材库 IPC（V2.1）

| 通道 | 方向 | 说明 |
|---|---|---|
| `media:list` | R→M | 素材目录列表（沿用 V2.0） |
| `media:get-bindings` / `media:set-bindings` | R→M | 读写 `mood-bindings.json`（主进程为绑定唯一数据源） |
| `media:pick-import` | R→M | 批量导入文件对话框：格式/体积校验 → 复制入库 → 广播目录变化 |
| `media:delete-item` / `media:rename-item` | R→M | 删除 / 重命名素材，联动解除或改写绑定并双向广播 |
| `media:preview-item` | R→M | "试穿"：向宠物窗口下发临时预览素材（传 `null` 结束试穿） |
| `media:save-removed-bg` | R→M | ★V2.2 保存去背景结果：写入 `<原名>-nobg.png`，可同时绑定情绪，成功后广播素材库变化 |
| `pet:command`（`mood-media-sync` / `media-library-changed` / `mood-media-preview`） | M→R | 宠物端同步绑定 / 素材目录索引 / 试穿素材；收到主进程回包时跳过本地上报（防环） |
| `media:bindings-changed` / `media:library-changed` | M→R | 素材库窗口实时刷新绑定与素材网格 |

## 5.4 数据与 IPC

沿用 V1.0 全部 IPC；面板与宠物共用本地数据文件；主进程行情结果通过现有 IPC 供双方取用。V2.1 起素材绑定关系存于 `Data/mood-bindings.json`，由主进程统一读写并广播（见 5.3.1）。

# 7. 风险与待确认项

| # | 项 | 说明 |
|---|---|---|
| 1 | 表情图形象一致性 | 多表情图切换方案的固有风险：happy/sad 与 idle 造型（毛色/角型）可能存在轻微漂移，需视觉验收；严重时退回 CSS 叠加方案 |
| 2 | 去底质量 | flood-fill 去白在毛缘/口鼻高光处可能残留白边或误挖，需放大目检，必要时调阈值重新生成 |
| 3 | 透明窗口性能 | 透明窗口 + 悬浮动画对 GPU 占用可控；待机动画保持低频、低位移 |
| 4 | 实际参考形象还原度 | 已按"3D 电影渲染金黄毛绒牛"候选定稿；如与用户参考图仍有较大差异，可提供文字描述后重出 |

# 8. 验收要点

1. 宠物为透明置顶小窗，无边框、不进任务栏、可左键拖动；
2. 右键弹出菜单，各项功能可达；
3. 自选/持仓/搜索/盈亏/快照功能与 V1.0 行为一致；
4. 行情变化驱动宠物表情在 4 态间正确切换；
5. 管理面板单实例，关闭后宠物不受影响，"退出"完整退出；
6. 打包产物含宠物素材，安装后可正常使用。
7. 素材库小窗可从右键菜单打开，单实例复用，与宠物窗口同时工作；
8. 素材库内导入 / 删除 / 重命名 / 绑定素材后，宠物与右键菜单显示即时一致，无需重启；
9. 素材"试穿"不影响绑定，点停止或关闭素材库后恢复原状；
10. 关闭素材库不影响宠物驻留，仍由菜单"退出"统一收口。
11. 静态图「去背景」能生成透明 PNG，阈值与边缘羽化滑杆实时生效且不重复推理；GIF / 视频按钮为禁用态；
12. 去背景结果支持「仅保存」与保存时绑定情绪，保存后素材库列表与宠物同步刷新，原图不被修改；
13. 托盘图标常驻，管理面板最小化后左键可唤回、右键菜单各项可用，桌宠可被复位到主屏右下角；
14. 自选股与持仓股行尾「删除」按钮可用，二次确认后列表与盈亏即时重算，`watchlist.json` / `holdings.json` 同步更新。
