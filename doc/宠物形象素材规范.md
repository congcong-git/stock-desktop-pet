# 宠物形象素材规范

> 目的：把"内置形象"从 3 张静态图升级为**一套可动、可替换的形象体系**。
> 本文是美术替换的交付依据——**按规范产出文件、覆盖同名文件即可，代码无需改动**。
>
> 当前状态：已全线切换为 **WebM 动画形象**。7 个形象（`idle` / `happy` / `sad` / `awake` / `rest` / `doze` / `sleep`）
> 与 2 个点击动作（`pat` / `wag`）均为 webm，旧的 PNG 素材已全部移除。

---

## 1. 文件位置与命名

```
src/assets/pet/
  idle.webm     待机（持平）
  happy.webm    开心（盈利）
  sad.webm      沮丧（亏损）
  awake.webm    开盘前（伸懒腰）
  rest.webm     午间休市（休息）
  doze.webm     收盘后（打盹）
  sleep.webm    周末 / 节假日（睡觉）

  pat.webm      点击动作：被摸头（含手）
  wag.webm      点击动作：站起来摇尾巴
```

- 构建脚本会**整目录复制** `src/assets/pet/` → `dist/assets/pet/`，新增文件自动生效，不用改构建配置。
- 索引在 `src/pet.jsx` 的 `BUILTIN_MEDIA` 常量里，key 与上表文件名一一对应。

## 2. 形象清单与设计指引

### 2.1 情绪形象（由当日盈亏决定，交易时段常驻）

| key | 场景 | 动作建议 |
|---|---|---|
| `idle` | 持平 | 轻微呼吸、偶尔眨眼，安静站姿 |
| `happy` | 盈利 | 轻快弹跳、摇尾巴、眯眼笑 |
| `sad` | 亏损 | 低头、耳朵/尾巴下垂、缓慢起伏 |

### 2.2 状态形象（非交易时段独立形象）

| key | 场景 | 动作建议 |
|---|---|---|
| `awake` | 开盘前 | 伸懒腰、还没完全睡醒 |
| `rest` | 午间休市 | 坐着/趴着，缓慢呼吸，眼睛半闭 |
| `doze` | 收盘后 | 打盹，闭眼，身体轻微起伏（配合右上角「Zzz 打盹中」角标） |
| `sleep` | 周末 / 节假日 | 蜷缩熟睡，幅度更小更慢（配合「Zzz 睡觉中」角标） |

> **交互唤醒**：非交易时段单击宠物，会临时切回**情绪形象**回应（"被摸醒"，露出笑脸或哭脸）并说今日盈亏，
> 3.5 秒后自动回到状态形象。所以两套形象要**同比例、同构图**，切换才不跳。

### 2.3 交互动作（代码已就绪，等素材）

单击宠物会随机播放「摸头」或「摇尾巴」，**播放 2 秒后自动回到点击前的形象**（睡觉时点 → 播动作 → 回睡觉）。

| 文件 | 时长 | 内容 |
|---|---|---|
| `pat.webm` | 2 秒 | 一只手伸过来摸头 + 牛乖乖被摸的反应（低头 / 眯眼 / 蹭手） |
| `wag.webm` | 2 秒 | 牛站起来摇尾巴 |

- **合并单文件**：手与牛画在同一个动画里，避免两层对不齐
- **关键**：与 7 个静态形象**同视角、同比例、脚底对齐**，否则点击会从当前形象"跳"到动作形象
- 素材缺失时自动降级为 CSS 变换动画（对静态图仍可见），不会空窗
- 播放期间不再叠加 CSS 变换，避免"动两遍"
- 素材放进 `src/assets/pet/` 即自动启用，无需改代码

## 3. 技术规格

| 项 | 要求 |
|---|---|
| 显示区 | 216 × 240 px（窗口 240 × 300，底部留给状态胶囊） |
| 建议出图尺寸 | 432 × 480（2 倍图），等比缩放，主体居中、**底部对齐** |
| 透明通道 | **必须带 alpha**；主体四周留 4–8px 安全边距，避免投影被裁 |
| 动画格式（当前在用） | **WebM（VP9 + alpha）**：真透明、体积最小、循环流畅 |
| 备选格式 | APNG：真透明兼容性好，但帧多时体积大 |
| 不推荐 | **GIF**：alpha 只有 1 bit，透明边缘会有明显锯齿白边，桌宠最忌讳 |
| 循环 | **首尾帧无缝衔接**，避免每轮"跳一下" |
| 时长 | 2–4 秒/循环；睡姿可更长（5–8 秒），呼吸感更自然 |
| 帧率 | 24–30 fps 足够，不必 60 |
| 体积预算 | 单个 ≤ 300 KB，7 个合计 ≤ 2 MB |

> 体积直接影响**自动更新包大小**：视频/动图不利于差分更新，超出预算会让使用者每次升级多下载几十 MB。

## 4. 一致性要求

整套形象必须是**同一只牛**：

- 同一视角（正面偏 3/4）、同一光影方向、同一轮廓尺寸与站姿基线
- 颜色与描边风格统一；情绪差异靠五官/体态/尾巴，不靠换配色
- 情绪形象与状态形象的**主体大小、脚底位置一致**，切换时不跳变

## 5. 替换步骤

1. 按上表命名产出文件（如 `doze.webm`）；
2. 覆盖 `src/assets/pet/` 下的同名文件（若**换了格式**，需同步改 `src/pet.jsx` 的 `BUILTIN_MEDIA`：`kind` 改 `"video"`、文件名改实际扩展名）；
3. `npm start` 自查：

| 检查项 | 方法 |
|---|---|
| 三个情绪形象 | 右键 → 素材库管理，试穿或直接绑定查看 |
| 四个状态形象 | 现在处于收盘后，应看到 `doze`；改系统时间或在代码里临时指定可看其他状态 |
| 交互唤醒 | 单击宠物，应从状态形象切到情绪形象 + 播动画，几秒后回到状态形象 |
| 透明边缘 | 拖动到深色/浅色壁纸上看是否有白边 |
| 循环无缝 | 盯 2–3 个循环，看衔接处是否跳帧 |
| 资源占用 | 任务管理器看长时间常驻的 CPU 占用（视频解码会持续消耗） |

4. 确认无误后按正常流程发版（`npm version patch` → 推送）。

## 6. 自定义与回退规则（素材库已支持 7 槽位）

- **槽位**：素材库管理分「情绪形象」3 槽 +「状态形象」4 槽，均可绑定图片 / 动图 / 视频。
- **回退规则**（渲染层 `src/pet.jsx`）：
  1. 用户为该槽位绑定的素材（若素材被删除则失效）；
  2. 状态槽位未绑定时 → 自动沿用用户绑定的**待机形象**（避免自定义形象的用户在睡觉时段穿帮回内置形象）；
  3. 全部未绑定时 → 内置 `BUILTIN_MEDIA`。
- **新旧绑定兼容**：老版本只有 3 个情绪槽位的数据不受影响；新增 4 个状态槽位默认为空，走回退规则。

## 7. 已知待办

- 性能降级策略（长时间无交互 / 窗口不可见时暂停视频解码）未实现，按实测 CPU 占用再决定。
- 素材自带动画时已在 CSS 关闭叠加的循环动画（`.pet-root--video`）；若美术希望保留轻微浮动，可调整该规则。
- 点击动作素材目前是"通用一套"，不区分情绪 / 状态（例如睡觉时被摸头与开心时被摸头反应相同）。
